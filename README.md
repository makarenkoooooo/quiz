📦 Приложение Викторина (Quiz App)
🚀 Обзор
Этот код представляет собой React-компонент для приложения викторины. Основная задача компонента — настроить корневые компоненты для маршрутизации и определить положение всплывающих уведомлений.

🔍 Подробности кода
Используется библиотека react-hot-toast для отображения уведомлений (тостов).

Маршрутизация настроена с помощью BrowserRouter из библиотеки react-router-dom.

Компонент Suspense используется для отображения заглушки ("Загрузка...") во время подгрузки маршрутов.

Основной контент приложения представлен компонентом AppRoutes, который управляет маршрутами приложения.

Для установки всплывающих уведомлений внизу по центру экрана используется компонент Toaster с параметром position: "bottom-center".

✅ Возвращаемое значение
React-элемент, содержащий корневую структуру приложения.

🎯 Общая цель
Создание базовой структуры приложения: маршрутизация и управление всплывающими уведомлениями.

⚙️ Компонент — Setup
Компонент React, который позволяет пользователю настроить параметры викторины перед её началом.

🔹 Краткое описание
Название компонента: Setup

Назначение: Настройка параметров викторины перед началом игры

Возвращаемое значение: React-элемент компонента

📄 Детали кода
Компонент взаимодействует с контекстом приложения через хук useAppContext.

Для получения категорий викторины используется хук useAxios, делающий запрос к API. Результат сохраняется в переменную response.

При ошибке загрузки отображается сообщение об ошибке.

В случае успешной загрузки (или во время ожидания) отображается форма настройки викторины: выбор категории, уровня сложности, типа вопросов и количества вопросов.

Обработчик handleSubmit вызывается при отправке формы, проверяет заполненность полей и перенаправляет пользователя на страницу вопросов (/questions).

Обработчик handleChange отслеживает изменение количества вопросов и обновляет его в контексте.

🎯 Общая цель
Предоставить пользователю возможность настроить викторину перед её началом и управлять переходом между страницами.

❓ Компонент — Questions
Компонент React для отображения и обработки вопросов викторины.

🔹 Краткое описание
Название компонента: Questions

Назначение: Отображение вопросов и обработка ответов в викторине

Возвращаемое значение: React-элемент компонента

📄 Детали кода
Компонент взаимодействует с контекстом приложения через хук useAppContext.

Через useAxios отправляется запрос к API с параметрами, зависящими от настроек (категория, сложность, тип и количество вопросов).

После получения ответа правильный ответ перемешивается с неправильными.

При выборе варианта ответа вызывается handleClick: если ответ верный, увеличивается счёт, затем переходит к следующему вопросу или на страницу /score.

При ошибке или загрузке отображается соответствующее сообщение.

При успешной загрузке отображается текущий вопрос, варианты ответов и текущий счёт.

🎯 Общая цель
Предоставление вопросов и вариантов ответов пользователю и обработка этих ответов с учётом правильности.

🎉 Компонент — Finish
Компонент React для отображения экрана завершения викторины и обработки событий на этом этапе.

🔹 Краткое описание
Название компонента: Finish

Назначение: Отображение финального экрана и обработка кнопки "Сыграть снова"

Возвращаемое значение: React-элемент компонента

📄 Детали кода
Компонент использует useAppContext для получения счёта и сброса состояния.

При монтировании компонента срабатывает useEffect, который запускает анимацию конфетти.

При нажатии на кнопку "Сыграть снова" вызывается handleClick: сбрасывается счёт и количество вопросов, после чего происходит редирект на главный экран.

Отображается информация о количестве правильных ответов и общем количестве вопросов.

🎯 Общая цель
Показать пользователю результат викторины, эффект завершения, и дать возможность начать заново.
